# Sqwish Labs — 4x/7x RTX PRO 6000 open-weight campaign: ranked recommendation (3 Sep 2026)

Conventions used below: sizes are decimal GB of safetensors actually on disk (not the HF "Parameters" element count); "spare" is against 384 GB / 672 GB nominal; the ≥15% headroom rule is applied; AA = Artificial Analysis Intelligence Index v4.1.1. sm_120 kernel rules applied throughout: FP8/NVFP4 dense linears → `--kernel-config.linear_backend b12x`; W4A4 NVFP4 MoE experts → `--moe-backend flashinfer_cutlass` (never `marlin`, which is the W4A16 path measured at −40%); MXFP4 MoE → `--moe-backend flashinfer_cutlass --quantization-config.moe.activation mxfp8`. ModelOpt **W4A16**_NVFP4 mixed builds (Ornith official, nvidia Nemotron/Muse builds) always land on Marlin — treat those as quality/VRAM rows, not throughput rows.

Baseline already measured on the 4x node: GLM-5.3-Flash 57, Qwen3.8-27B 52, MiniMax-M3 45, Inkling(-Small) 41-42, Nemotron 3 Ultra 38, Muse Glimmer 35, gpt-oss-120b 24, Nemotron 3.5 Lightning 24.
